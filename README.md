# Bvito

Учебная доска объявлений на Vue 3, Node.js, Express и MongoDB. Проект сделан для практики работы с интерфейсом, серверными запросами, базой данных и внешним API.

## Что можно попробовать

- Искать по словам в названии и описании. При сортировке по совпадению слова в названии имеют больший вес.
- Фильтровать по категории, подкатегории, цене и состоянию вещи.
- Открывать объявление по прямой ссылке, сохранять его в избранное и бронировать. Контакты продавца открываются покупателю после бронирования. Встречу стороны согласовывают напрямую.
- Вести собственные объявления, менять контакты в профиле и просматривать свои брони.
- Смотреть цены в рублях, юанях, белорусских рублях и тенге. Для пересчёта сервер загружает [официальный курс Банка России](https://www.cbr.ru/development/sxml/), кэширует его на час и сообщает, если курс временно недоступен. В базе цены хранятся в рублях.

## Запуск

Нужны Node.js 20.12 или новее и запущенная MongoDB. По умолчанию приложение использует локальную базу `bvito_portfolio`.

```sh
npm ci
npm run seed
npm run build
npm start
```

Откройте [localhost:3000](http://127.0.0.1:3000). На странице входа можно выбрать один из трёх готовых аккаунтов — **maria**, **ilya**, **lena**. Общий пароль — **demo2026**. У них есть свои объявления, контакты и избранное. Контакты и фотографии демонстрационные. Для проверки бронирования войдите в один аккаунт и откройте объявление другого.

Для разработки запустите `npm run server` и `npm run dev` в отдельных терминалах. Vite перенаправляет запросы к API на порт 3000.

## Структура

- `src/pages` — каталог, карточка объявления, формы, профиль и страницы ошибок.
- `src/components` — общие элементы интерфейса.
- `server` — учётные записи, объявления, MongoDB и курсы валют.
- `shared/categories.json` — категории и подкатегории для клиента и сервера.

В каталоге выдача разделена на страницы, фотографии сохранены в WebP, а формы и личные страницы загружаются по мере открытия. Пароли хэшируются, сессии хранятся в MongoDB, а изменения объявления доступны его автору.

## Размещение

Для публичной версии нужен хостинг Node.js и доступная ему MongoDB. Express раздаёт собранный Vue и API с одного адреса. На хостинге задайте `MONGODB_URI`, `HOST=0.0.0.0`, `NODE_ENV=production` и порт, который ожидает платформа. Команда сборки — `npm ci && npm run build`, команда запуска — `npm start`. Запустите `npm run seed` один раз с той же строкой подключения, чтобы наполнить демонстрационную базу.

Иллюстрация маскота и фотографии демо-объявлений созданы для этого проекта.
